# Prometiam Risk Intelligence (`prometiam-risk-mcp`)

> Model Context Protocol server for the **Prometiam Risk Intelligence API** — official company-registry data for Spain, France, the UK, Ireland, Poland, Norway, Finland, Sweden, Croatia, Belgium, Denmark, Estonia, Slovakia, Switzerland, Latvia, Cyprus, Romania, Lithuania, Canada, Australia, Japan, Israel, Singapore, Colombia, Taiwan, Czech Republic, Germany, the Netherlands, Brazil, Argentina, Ukraine, Serbia, Slovenia, South Korea, Malta, Ecuador, Chile, Greece, Moldova, Mexico, the United States (state registers, SEC EDGAR, GLEIF) and every other live country, and LEI-registered entities in more than 20 other jurisdictions, including Italy, India, Austria, Luxembourg and China, plus directors, corporate events, insolvency, VAT/LEI lookup, sanctions screening, annual financial statements, public-procurement awards (Spain, France, the UK, Colombia from June 2015, Australia and Chile from 1 January 2025; from TED above the EU thresholds only: Ireland, Poland, Norway, Finland, Sweden, Denmark, Estonia, Latvia, Lithuania, Slovakia, the Czech Republic, Croatia, Romania and Belgium, the last eleven since November 2023) and public-buyer risk scores (Spain, France, Romania), as native MCP tools for Claude Desktop, Cursor, Continue, Cline, and any MCP-compatible client.

## Install

```bash
npx -y prometiam-risk-mcp   # one-shot run, no install needed
# or
npm install -g prometiam-risk-mcp   # global install for the bin
```

## Configure

**It works without any key.** The server ships with a shared demo key — 30 requests a minute and 2,000 a day for everyone using it — so the first tool call answers right after `npx`. When the shared quota is used up the error tells you how to continue.

For your own credits — **14-day free trial: 500 credits; a card is required, nothing is charged for 14 days** — sign up at <https://www.prometiam.com/signup?utm_source=mcp> and set the key as an environment variable:

```bash
export PROMETIAM_API_KEY="rk_live_..."
```

## Hosted endpoint (no install)

The same 39 tools are served over Streamable HTTP at `https://api.prometiam.com/functions/v1/mcp`: no `npx` and no local process. Send your own key as `Authorization: Bearer rk_live_...` (`X-API-Key` works too). With no key it runs in demo mode on the shared demo key (30 requests a minute and 2,000 calls a day for everyone, the quota the npx demo shares); in demo mode some tools, such as `sanctions_screen` and `events_search`, answer `upgrade_required`. The endpoint holds no data and no secret: each tool call is one API request, priced in credits like the REST call (sanctions screening is beta). Your own key works only from a client that can send a request header.

Claude Code:

```bash
claude mcp add --transport http prometiam https://api.prometiam.com/functions/v1/mcp --header "Authorization: Bearer rk_live_..."
```

Cursor (`.cursor/mcp.json` in the project, or `~/.cursor/mcp.json`):

```json
{
  "mcpServers": {
    "prometiam": {
      "url": "https://api.prometiam.com/functions/v1/mcp",
      "headers": { "Authorization": "Bearer ${env:PROMETIAM_API_KEY}" }
    }
  }
}
```

## Privacy and data residency

- All requests hit the Prometiam Risk Intelligence API in **EU** (AWS eu-central-1, Frankfurt).
- The MCP server adds **no telemetry of its own** — it just forwards requests to the API.
- Officer data is processed under GDPR Article 6(1)(c) (legal obligation of public registries) and 6(1)(f) (legitimate interest in fraud prevention).
- Mostly read-only. The mutating tools are `monitor_subscribe`, `monitor_stop`, `sanctions_watch` and `sanctions_unwatch` (create or delete a monitoring subscription or a sanctions watchlist entry tied to your key); every other tool is read-only.
